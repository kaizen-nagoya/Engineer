# Q1 Qiita以外に、プログラマのAdvent Calendarを作れる場所はありますか。

A1 by ChatGPT

はい、あります。Qiita以外にも、プログラマやエンジニアがテーマ別に記事を持ち寄る「Advent Calendar」を開催できるサービスがあります。

特におすすめなのは Adventar です。

ただし、次の2種類を区別すると選びやすくなります。

- カレンダー管理サービス：25日分の投稿枠を作り、参加者が担当日を予約する。
- 記事公開サービス：参加者が技術記事を執筆・公開する。記事の公開先は統一する必要がありません。

| GitHubを中心に運営   | GitHub＋Adventar |

## 3. 私なら、こんな企画を考えます

これまで取り組まれているオープンソース活動や技術者教育とも関連しますが、Qiitaの既存テーマに限定しない独自の技術者Advent Calendarを作るのも面白いと思います。

例えば、

- C/C++ Advent Calendar
- AUTOSAR Advent Calendar
- UML・SysML Advent Calendar
- 組込みソフトウェア Advent Calendar
- ROS 2・ロボティクス Advent Calendar
- 生成AIプログラミング Advent Calendar
- オープンソース開発 Advent Calendar
- プログラミング教育 Advent Calendar

特におすすめは、Adventarをカレンダー管理に使い、記事はQiita、Zenn、Researchmap、GitHubなど自由に公開する方式です。

こうすれば、特定の投稿サービスに依存せず、技術者の成果を横断的に集められます。

また、12月の25日間だけでなく、1年間を通じて毎週1人が技術情報を発信する仕組みに発展させることもできます。
