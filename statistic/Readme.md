## 2. 「経験・勘・度胸」を数学で説明する

この部分が教材の知的な中心になります。

ただし、経験・勘・度胸がそのまま一対一で数学に置き換わるわけではありません。それぞれを、数学的に扱える要素に分解するのが適切です。

## 経験・勘・度胸の工学的解釈

① 経験 → 統計

過去に何が起きたか。どんな条件で成功・失敗したか。

\\[ \text{経験} \rightarrow \text{観測データ・分布・傾向} \\]

例：100回の作業で何回失敗したか。失敗がどの条件で多かったか。

② 勘 → 確率・仮説

まだ確定していないが、何かがおかしいと気づく。

\\[ \text{勘} \rightarrow \text{仮説・条件付き確率} \\]

例：機械の音が少し違う。故障の可能性が高まったのではないか。

③ 度胸 → 意思決定・危機管理

不確実な状況で、どの行動を選ぶか。

\\[ \text{度胸} \rightarrow \text{期待損失・判断基準} \\]

例：生産を続けるか、停止して点検するか。

ここで、視聴者に覚えてもらう数式は一つで十分です。

リスクの基本的な考え方

\\[ R=P(\text{事故})\times L(\text{損失}) \\]

P：事故の発生確率、L：発生した場合の損失。単純化した期待損失のモデルです。

例えば、機械の故障確率が1%で、故障した場合の損失が100万円なら、

\\[ 0.01\times1,000,000=10,000\text{円} \\]

期待損失は1回当たり1万円です。

これなら、点検費用や予防保全費用と比較して、対策を考えられます。

ただし、重大事故では平均的な期待損失だけで判断してはいけません。死亡・人身事故など、許容できない結果については、別途安全上の制約や対策基準を設けます。

### ここで伝えるべき重要なこと

- 経験は、データの蓄積になる。
- 勘は、異常の発見や仮説を作る能力になる。
- 度胸は、不確実性の中で判断し、行動する能力になる。

つまり、ベテランは単に長く働いた人ではありません。大量の経験から、まだデータになっていない異常を発見できる人なのです。

# 4. 人間と生成AIの役割分担

ここは、教材のメッセージを最も強く打ち出す部分です。

従来の自動化は、人間が行っていた作業を機械に置き換えるという考え方が中心でした。

しかし、生成AIの活用では、別の考え方ができます。

| 人間が担当すること    | 生成AIが支援すること  |
| ------------ | ------------ |
| 問題を発見する      | 過去の類似問題を探す   |
| 新しい仮説を考える    | 仮説を比較・整理する   |
| 現場で異常を感じる    | センサー・記録を分析する |
| 価値や優先順位を判断する | 判断材料を提示する    |
| 新しい方法を試す     | 実験結果を整理する    |
| 結果に責任を持つ     | 判断根拠や履歴を記録する |

特に重要なのは、次の違いです。

人間は、何を問題とするかを発見する。AIは、蓄積された知識を利用して問題解決を支援する。

ただし、AI自身も新しい仮説や問題候補を提示できます。人間だけが創造できるという意味ではありません。問題の定義、価値判断、安全上の許容範囲、最終的な責任は、人間と組織が担う必要があります。

また、生成AIに学習させるとは、必ずしも毎回モデル自体を追加学習させることではありません。

- 記録を検索できるようにする（RAG）
- 判断事例をデータベース化する
- 良い回答例で追加学習する（SFTなど）
- 作業の結果から評価・改善する

このような複数の仕組みを含めて考えると、現実的です。

# 6. 教材に使うデータの設計

動画を単なる精神論にしないために、実際に数字を使った例を入れます。

例えば、工場の機械の故障を考えます。

次のような仮想データを教材用に用意します。

| 状態      | 故障件数 | 検査件数  | 故障率   |
| ------- | ---- | ----- | ----- |
| 通常時     | 2    | 1,000 | 0.2%  |
| 異音あり    | 12   | 200   | 6.0%  |
| 振動増加    | 15   | 150   | 10.0% |
| 異音＋振動増加 | 20   | 100   | 20.0% |

説明用の架空データです。実際の故障率を示すものではありません。

これを使えば、次のような教材展開ができます。

1. 熟練者が異音に気づく。
2. 振動の増加にも気づく。
3. 過去の故障記録を調べる。
4. 異音と振動の組み合わせで故障率が高いことを発見する。
5. 故障する前に点検する仕組みを考える。
6. この判断を記録して生成AIで再利用する。

ここで一つ、統計教育上の注意があります。

上の表だけでは、異音と振動が独立しているか、同じ故障原因によるものか、因果関係があるかは分かりません。母数、観測期間、機械の種類、検査条件も必要です。

この点をあえて教材に入れると、統計とは数字を並べることではなく、数字の意味を考えることだと伝えられます。

## 生成AIに渡すデータの基本構造

例えば、ベテランの判断を次のようなデータとして残します。

```
{
  "case_id": "MACHINE-001",
  "observation": {
    "sound": "通常と異なる異音",
    "vibration": "通常より増加"
  },
  "hypothesis": [
    "軸受の劣化",
    "回転部の異常"
  ],
  "decision": "運転停止して点検",
  "reason": "故障拡大と二次被害を防ぐ",
  "action": "振動測定と軸受点検",
  "result": "軸受の劣化を確認",
  "lesson": "異音と振動増加の同時発生に注意"
}
```

このデータには重要な意味があります。

単に「故障した」という結果だけではなく、

- 何を観察したか
- 何を推測したか
- どう判断したか
- 何を実行したか
- その結果はどうだったか

という人間の思考過程を残しています。

これが、生成AIにとって価値のある教材データになります。

ただし、判断記録には誤りや思い込みも含まれます。成功事例だけでなく、失敗事例、判断の不確実性、反対意見、適用条件も記録し、検証してから活用することが重要です。

## 人間とAIによる知識創造サイクル

1. 人間が現場で経験する

5. 生成AIで再利用する

   類似事例を探し、知識を組み合わせる。
6. 人間が新しい課題に挑戦する

   AIの回答を検証し、新しい経験を作る。

新しい経験が、次の知識になる。

人間 → 知識化 → 生成AI → 人間という循環が続く。

# 9. YouTube Shortsを制作するときの共通フォーマット

8本の動画で、映像と話の構造を統一すると、シリーズとして見てもらいやすくなります。

| 時間     | 内容       | 演出         |
| ------ | -------- | ---------- |
| 0～3秒   | 意外な問い    | 大きな文字・強い一言 |
| 3～12秒  | 身近な事例    | 料理・自動車・工場  |
| 12～30秒 | 科学的な説明   | 数字・図・簡単な数式 |
| 30～45秒 | 生成AIとの関係 | 人間とAIの役割分担 |
| 45～60秒 | 結論       | 覚えてほしい一言   |

例えば、第1話の冒頭は次のようにします。

「ベテランの勘は、AIに置き換えられるでしょうか？」

そして最後は、

「違います。ベテランの勘をAIが使える知識に変えるのです。」

このように、最初に視聴者の常識を揺さぶり、最後に新しい考え方を提示します。

# 10. 教材としての評価基準

動画を作って終わりにせず、視聴者が何を理解したかを評価すると、教材としての価値が高まります。

| 評価項目   | 到達目標                 |
| ------ | -------------------- |
| 経験の理解  | 経験をデータとして説明できる       |
| 勘の理解   | 勘を仮説として説明できる         |
| 度胸の理解  | 不確実な状況での意思決定として説明できる |
| 統計の理解  | データから傾向を読み取れる        |
| リスクの理解 | 発生確率と損失を区別できる        |
| 属人性の理解 | 個人依存と熟練能力を区別できる      |
| AIの理解  | 生成AIに渡すべき知識を説明できる    |
| 人間の役割  | AI時代の人間の仕事を説明できる     |

動画の効果は、再生回数だけでなく、視聴後に「自分の仕事の経験を記録してみよう」と行動が変わったかでも評価したいところです。

# 11. 私が特に提案したい、教材の中心メッセージ

今回の企画で、最も大切にしたいのは次の考え方です。

# 属人性をなくすな。属人性を活用せよ。

従来の考え方

人によって仕事のやり方が違う。\
だから標準化して、誰でも同じ仕事ができるようにする。

これからの考え方

人によって違うからこそ、新しい発見が生まれる。\
その発見を記録し、検証し、生成AIによって共有する。

# 人間の能力を標準化するのではなく、人間の能力を共有可能にする。

ここには大きな違いがあります。

標準化だけを目指すと、平均的な仕事ができる人を大量に育てる方向に進みます。

一方、個々人の独自の発見や工夫を尊重すれば、組織全体の知識の幅を広げられます。

生成AIは、その知識を検索・比較・組み合わせるための手段です。

もちろん、すべての暗黙知を言葉やデータに変換できるわけではありません。身体技能や状況に依存する判断には、実演や共同作業による伝承も必要です。

最終的なキャッチコピー候補

1. 経験を科学に。勘を確率に。度胸を危機管理に。
2. 属人性こそ、人間の価値である。
3. ベテランの経験を、AIで社会の知識に。
4. AIに仕事を奪われるな。AIに経験を活用させよう。
5. 人間が発見し、AIが広げ、人間がまた挑戦する。

私の第一候補は 「経験を科学に。勘を確率に。度胸を危機管理に。」 です。短く、工学的な意味があり、シリーズ全体を貫けます。

次に制作するなら、8本を別々の動画にするだけでなく、各動画に共通の登場人物（新人・ベテラン・AI）を設定することをおすすめします。そうすると、専門知識のない視聴者もストーリーとして理解できます。

さらに、このアウトラインを基に、第1話から第8話までのナレーション原稿、秒単位のカット割り、画面表示文字、生成AI用の画像・動画プロンプトまで一貫して設計できます。
